## What it does
One installer, `fix/anim_final_1030.lua` (GENERATED by `tools/anim_final_build.py` from `fix/anim_final_1030/*`; round 1;
two-pass, round-stamped on WeaponConfig `AnimFinal1030Round`, checks every anchor first, keeps line endings, UNDO exact).
Four modules + small anchored edits in 10 scripts. **Every clip is found by name** in `ReplicatedStorage.Repository.AnimationSources`
(PublishedId live, the KeyframeSequence in Studio): a clip nobody has made yet plays nothing new, the old behaviour stays.
Firing, hit detection, reload / draw times and balance are unchanged.

## Guns [GUNSV2] (fix/guns_v2.lua, GENERATED by tools/guns_v2_build.py)
- Reads art/anim/guns/DONE.md (mesh ids, attachments) + art/guns/manifest/<Gun>.json (parts, pivots, boxes, colours, WrapChannel).
- Per gun Tool (name, attributes, Grip, Handle sounds kept): Handle = invisible 0.2 x 0.6 x 0.3 root (WrapSkip); one MeshPart per part
  (AssetService:CreateMeshPartAsync), no collision / query / touch, massless; moving parts = Motor6D named after the part (Part0 = its
  parent part, C0/C1 at the pivot); static parts welded; attachments Muzzle / Grip / ShellEject / Mag / ...; the old Muzzle's light +
  emitters move to the new Muzzle. DualPistols: its muzzles go on Barrel / LeftBarrel as "Muzzle" (the akimbo code reads those).
- Old visual parts -> ServerStorage._GunsV1.<Tool> (UNDO puts them back exactly, flash set included). Stamp: Tool attribute GunsV2.
- `--standin` builds plain Parts the size of each mesh box (tests only; fix/guns_v2_standin.lua).
- HolsterManager's worn copies clone the tool's parts and weld anything unwelded: works with the new rigs unchanged.
- Shells: a GUNSV2 gun's casing is a copy of its Round / LoadShell mesh, spawned at its ShellEject attachment.
- Status: mesh ids "pending upload" in DONE.md at the time of writing (the modeler uploads by Import 3D).
