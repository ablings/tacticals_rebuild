## Answers for the animators (wiring notes in notes/anim_style_targets.md)
- DiveAim: **author it upright**: the code pitches the root (aimed: 25% of DivePitch 62 = ~15 deg).
- Empty / tactical reloads play fitted to the gun's ReloadTime (the server's time is unchanged, "the code's lengths kept").
- Shotgun: Start fitted to StartDelay 0.2, Shell per shell fitted to ShellTime 0.5, End / EndEmpty after the last shell; a shot cuts.
- Breathing over a weapon Hold is code (Waist + shoulders); BreatheCalm / Heavy play only unarmed (Idle priority).
- Landmine: still thrown (no new rule); LandminePlace plays on a tap (the roll = set it down near you).
- Deaths: the ragdoll takes over at `Ground` / `Ragdoll` times in `AnimFinalConfig.Death.RagdollAt`.
