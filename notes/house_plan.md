# House: plan (duel map, 1v1 / 2v2 / 3v3)

A big two-storey modern suburban house; the layout and feel are inspired by a classic suburban test-site shooter map, with our
own models and wording. Work order: Lead's plan approved by Edward (2026-10-28, overnight). Data:
`notes/maps/house_layout.json` (generated by `tools/house_layout.py`, never hand-edited). Checker: `tools/house_check.py` ->
`notes/maps/house_checks.txt`. Images: `notes/maps/house_plan.png` (plan), `notes/maps/house_exposure.png` (exposure + who
gets there first). Kit list for the modeler: `briefs/kit-house.json`.

Plan coordinates: x east, y north (street and front door south, backyard north), z up; ground floor 0, upper floor 14.
World = ORIGIN + (x, z, -y). House inside 80 x 60; ground ceiling 13, upper ceiling 26; walls 1 thick.

  53 pieces; every one is a COLP box and a modeler mesh of exactly that size.

  arches; the gallery windows from the bedrooms onto the foyer.

## Builder's calls (flagged for Edward)
1. **A second, enclosed-upstairs back stair** (back hall -> landing, x 4..8.5). With one stair the only link between the floors
   is a single choke that one team holds; the back stair makes a loop (foyer - main stair - landing - back stair - back hall -
   kitchen), and each team gets its own stair. If Edward wants exactly one staircase, the plan has to change (and the spawns).
2. **Both teams spawn on the ground floor** (A living room, B kitchen; point-symmetric about the centre, one floor). Tried
   first: A downstairs / B upstairs. The ground is open plan and the bedrooms are closed boxes, so approach exposure differed
   ~50 % and spawn sight 25-75 %; furniture could not close it. The upper floor is now the contested high ground.
