# Performance settings [PERFSET] (2026-10-30, main PC, systems session)

Edward, after the lag test (notes/lag_test_1030.md): "now with the in game settings what can we turn off to lower this".
Built and tested in copies only (out/perfset/); **not in any live place, not published**. Ships with the next port (Edward's go).

## What the player gets (Settings > Video > Performance; every row is OFF by default, so nobody's game changes unless they pick it)
| Row | What it turns off | Was |
|---|---|---|
| Optimized Lighting | sun shadows, **every lamp's shadows**, bloom / depth of field / sun rays; stays off when a match map turns shadows back on | sun shadows + lobby bloom only, and the match map's lighting turned the sun shadows back on at match start (bug) |
| Optimized Textures | surface images (SurfaceAppearance, Texture, Decal) on **every map**; players' avatars keep theirs | the lobby map only |
| Fewer Lights (new) | lamps more than 70 studs from the camera (back on inside 62) | - |
| Low Effects (new) | explosions: no shadow-casting flash, sparks 60-90 -> 18, embers 40 -> 10, dust 30 -> 10, fireball 16-26 -> 8, no flying debris. Smoke and steam are never thinned (they block sight: thinner smoke would be an advantage) | - |
| Hide Far Screens (new) | in-world screens and signs stop drawing past 60 studs (player nameplates and markers untouched) | - |

## Measured (Studio Play, graphics level 21, same camera, each row on alone)
| Scene | Off | Optimized Lighting | Optimized Textures | Fewer Lights | Hide Far Screens | All five |
|---|---|---|---|---|---|---|
| Lobby hub (Tacticals_rebuild.rbxl copy) | 1,993k tris / 2,318 batches | **200k / 197** | 1,968k / 2,264 | 1,305k / 1,518 (18 of 148 lamps on) | 1,991k / 2,304 (376 screens capped) | **186k / 162** |
| House 3v3 (Test build) | 304k / 648 | **77k / 171** | 322k / 675; texture memory 151 -> 127 MB | 304k / 648 (36 of 83 lamps on) | 307k / 668 (120 capped) | **76k / 180** |
- Low Effects, frag in House: debris chunks 4 -> 0, shadowed flash lights 1 -> 0.
- Turning every row back off restores the exact start (lobby 2,000k / 2,337, 14 lamp shadows, 1,603 SurfaceAppearances back).
- Saves: the server's SettingsConfig.Sanitize keeps the new rows (bad value -> default off); defaults all off. No new console errors.
- The 0.25-0.32 s frag hitch of the lag test did not come back on later frags (worst frame 20 ms at 60 fps, with and without Low
  Effects): it looks like a first-explosion-of-the-session load. Cheapest fix (not done, not a setting): preload the explosion
  textures and sounds at match start.
