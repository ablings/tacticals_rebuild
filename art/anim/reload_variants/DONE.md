# Ammo-aware reload variants: DONE (reload-variants animator, 2026-10-30, round 1)

The reload looks different by rounds left; **every variant of a gun is exactly the gun's runtime ReloadTime long** (so the
code's `AdjustSpeed(track.Length / ReloadTime)` is 1.0) and all variants of a gun share their anchor markers (MagOut / MagIn /
Ready, or CylinderOpen / ShellIn / CylinderClosed) on the same frames. Design and ranges: `notes/reload_variants_design.md`
(trainer, RIVALS study in `notes/reload_variants_ref.md`). Style: Grounded Tactical.

- **Rig / pipeline:** Edward's Starter Blocky rig copy (`art/anim/rig/`), the weapons animator's `rbxanim` (read-only import)
  and gun manifests; gun parts keyed in the same action. Sources `blender/clips/rv_*.py`; build
  `blender -b art/anim/rig/Starter_Blocky_Rig.blend --python art/anim/reload_variants/blender/make.py -- rv_<gun>`
  (asserts each clip's length = the gun's ReloadTime; POPCHECK lists carried-part jumps) -> `blender/sets/rv_<gun>.blend` +
  `out/anim_reload_variants/json`. Install: `install_sources.lua` (generated by `tools/gen_install.py`, ids from
  `published.json`).
- **Studio proof:** installed in `out/anim_reload_variants/anim_reload_variants.rbxl` (a copy of the weapons animator's place;
  Studio id in `out/anim_reload_variants/studio_id.txt`). Each variant loaded as an AnimationTrack on a default R15:
  `studio_lengths.txt` here (every length exact, markers listed).
- **Captures:** `captures/anim/reload_variants/<gun>_{fp,game,side}_1x.png` (rows = the base reload time-scaled to the game
  length + every variant; columns = 10 fps of game time, so one column = one moment in game) and `<gun>_fp_025x.png`
  (every 60 fps frame over the window where the variants differ). Rendered in Blender from the same rig with the exact R15
  part boxes and the guns' part boxes (moving parts olive, rounds brass): the full-size Studio stage was held by the weapons
  animator's publishing all session.
- **Grade:** pending (HQ's fresh grader runs after this task).

## Code hooks (for systems; the animator does not edit game scripts)
1. **Pick the variant at reload start** from the rounds left (`getAmmo()` before `ReloadWeapon:FireServer()`), play
   `<Prefix>Reload_<Variant>` (fallback: the current `<Prefix>Reload`), `AdjustSpeed(track.Length / ReloadTime)` as now.
   Proposed config per gun: `ReloadVariants = { {Max = 0, Clip = "Dry"}, {Max = 6, Clip = "Drop"}, {Max = 99, Clip = "Retain"} }`
   (first row with `Max >= rounds left`). Ranges per gun: the table above / the design's summary table.
   Pistol-prefix guns: Pistol and Suppressed share the clips (Suppressed plays them at 1.3/1.5); Rifle-prefix: Auto Rifle and
   Semi-Auto (2.2/2.5). Mini Uzi, Auto Rifle, Semi-Auto, Sniper and Shotgun currently have `AnimationSourcePrefix = "Pistol"`
   in WeaponConfig: set them to `SMG` / `Rifle` / `Rifle` / `Sniper` / `Shotgun` (the weapons animator's wiring note 1).
2. **Markers:** MagOut, MagIn, Ready (gun live again), MagStowed, MagHide / MagShow (hide the dropped mag), MagTug, MagTap,
   PressCheck, SlideRack, BoltClosed, RoundCheck (sounds). Revolver: CylinderOpen, ShellEject (value = the plucked round on
   Pluck clips), RoundHide / RoundShow (value = `Round1`/`Round2`: hide a plucked casing, show the fresh round in the hand
   and give it the live look), MagHide / MagShow (value `Rounds`: hide all rounds after the dump, show the loader set),
   LoaderShow / LoaderHide (the `SpeedLoader` prop), ShellIn, CylinderClosed. Shotgun: ShellIn, PumpClosed, GateSlap.
3. **Revolver look per round:** at reload start give each `RoundN` the live (brass + tip) or spent (casing) look: spent
   chambers are Round1.. upward (Round1 = top chamber = the last one fired; Round2 the next one a +60 index brings up).
   Dump shows 1-3 live + spent falling, Dry six casings.
4. **Shotgun:** reload started at 0 -> `ShotgunReloadStart_Dry` then `ShotgunReloadShell_Port` for the first shell; tube shells
   alternate `ShotgunReloadShell` (A) / `ShotgunReloadShell_B`; the shell that fills the tube plays `ShotgunReloadShell_Last`;
   end with `ShotgunReloadEnd` for every count (`ShotgunReloadEndEmpty` no longer needed). A shot still cuts any shell clip.
5. **Left hand:** every clip has a `...Left` mirror (Handle under LeftHand), as the weapons set.

## Rig changes needed (for the modeler)
- **Revolver:** split `Rounds` into `Round1`..`Round6`, one per chamber, Motor6D parent `EjectorRod` (so the extractor stroke
  pushes them), pivot = each round's centre: Round k at angle 90 - 60(k-1) deg on the 0.09 chamber circle around the cylinder
  axis (0, 0.37), z -0.4685 (Handle space; exact numbers in `blender/clips/rv_revolver.py round_rest`). Add a `SpeedLoader`
  prop (Motor6D to Handle, pivot (0, 0.37, -0.30), hidden by code outside LoaderShow..LoaderHide). No `LooseRound` needed:
  the plucked round itself is carried. Until the split exists the Dump / Dry clips still move the one-piece `Rounds`.
- **Dual Pistols:** the remodel already has `LeftSlide` / `LeftMag` per gun (the design's SlideR/L, MagBaseR/L).
